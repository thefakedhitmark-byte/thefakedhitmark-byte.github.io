PLANEZONE – Privacy Policy

PLANEZONE is a private tool used only by the owner of the YouTube channel it is connected to. It uses the YouTube Data API to read the owner's active live broadcast and to update its title and description.

No data from other users is collected. The access token is stored only on the owner's own server and is never shared with third parties. Access can be revoked at any time at https://myaccount.google.com/permissions.
